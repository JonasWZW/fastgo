# FastGo：面向 Java / Python 开发者的 Go 工程化练习

这个仓库用于学习如何用 Go 快速、工程化地交付后端项目。学习顺序刻意安排为：

1. 先掌握工具链、模块、包、项目结构、测试和构建；
2. 再完成一个可运行、可测试、可部署的 HTTP 服务；
3. 最后集中补齐 Go 语法和语言细节。

贯穿项目暂定为 **Task API**：一个具备配置、日志、存储、测试、可观测性和优雅退出能力的任务管理服务。它足够小，可以快速迭代；又足够完整，可以覆盖真实后端项目的主要工程问题。

## 推荐学习方式

每章遵循同一个循环：

> 先理解工程问题 → 运行最小示例 → 自己修改 → 用测试或命令验收 → 更新知识账本

不要以“看完”为完成标准。只有对应产物能够运行、测试通过，并且能用自己的话解释关键取舍，才算完成一章。
